# 最小可玩模板：消失的备用钥匙

这个示例是档案工坊的发布门槛夹具，也是“从模板创建”使用的数据来源。它包含：

- 4个人物/地点实体与4条时间线记录；
- 文件、讯息、邮件、浏览记录、日历和系统日志内容；
- 6条可发现线索与1个声明式提示触发器；
- 2道总分100分的推理题及3个连续结果等级；
- 1张原创本地PNG封面，没有远程资源或可执行脚本。

运行 `npm run validate:editor-examples` 校验编译、引用和资源哈希；运行 `npm run package:editor-examples` 生成并重新导入 `.ldmproject` 与 `.ldmcase`。
