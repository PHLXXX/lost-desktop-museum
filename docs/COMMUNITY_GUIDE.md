# 档案交换站使用指南

从档案馆顶部进入“社区档案”。页面先读取 IndexedDB 缓存，再在需要时同步构建时固定的静态 Registry。搜索完全在本机执行，可按语言、难度、时长、标签、人工精选、安装与更新状态整理条目；默认只显示 `general` 与 `teen`，成熟主题需主动开启。

详情页展示内容提示、自动校验与人工精选的准确含义、版本、引擎要求、包大小、许可证、截图和 CHANGELOG。点击“安装到档案馆”后才下载完整包；下载完成先核对 SHA-256，再运行 `.ldmcase` 完整安全校验，最后仍需明确确认安装。安装完成不会自动开始调查。

已安装案件在“我的档案”标记为社区来源，可离线开始、保存和结算。详情页可检查更新、查看兼容影响、回滚或卸载；只删除资源可以保留进度。收藏、1—5 私人评分和纯文本备注只保存在本设备，不会形成公开评分。

“报告内容问题”只向 GitHub Issue 预填 caseId、版本、问题类型和 registry 版本；打开外部 GitHub 前会显示目标域名，不上传存档、推理或私人备注。本地导入案件没有社区校验标签，也不参与自动更新。
