# 档案工坊使用指南

档案工坊是 v0.4.0 的本地可视化案件制作工具。它不要求作者直接编辑 JSON，也不会把工程或资源上传到服务器。

## 完整工作流

1. 在档案馆选择“进入档案工坊”。
2. 新建空白工程、使用《消失的备用钥匙》模板，或复制两宗内置案件。
3. 在基本信息、人物、时间线、桌面和应用模块中录入内容。
4. 在线索模块选择来源、发现事件与声明式条件。
5. 在触发器模块配置白名单效果，并为安全模式和减弱动画提供替代效果。
6. 在推理模块设置问题、100 分评分和覆盖 0—100 分的结果等级。
7. 在资源管理器导入本地图片、音频或文本，填写用途和替代文本。
8. 打开校验中心，处理所有错误。
9. 点击“试玩”，使用真实游戏桌面验证完整调查流程。
10. 在发布模块导出 `.ldmcase`；工程备份使用 `.ldmproject`。

## 保存与恢复

- 编辑后 800ms 自动保存到 IndexedDB；顶部显示脏状态、保存中、已保存或失败。
- `Ctrl/Cmd + S` 立即保存，`Ctrl/Cmd + Z` 与 `Ctrl/Cmd + Shift + Z` 撤销/重做。
- 历史最多 80 步，相邻的同字段输入在 600ms 内合并。
- 快照最多保留 20 个，可查看、恢复和删除；恢复前会自动保留当前版本。
- 同一工程在第二个标签页默认只读。需要接管时必须在对话框确认。
- `.ldmproject` 包含工程和资源，可用于跨浏览器备份；同 ID 导入时可安装副本或替换，替换前创建快照。

## 资源规则

正式支持 PNG、JPEG、WebP、WAV、OGG、TXT 和 Markdown。导入会检查扩展名、MIME、文件签名、20MB 单文件限制和 SHA-256；大于 1MB 的哈希优先交给 Web Worker。第三方案件不接受 SVG、远程 URL 或可执行内容。

## 键盘操作

- `Ctrl/Cmd + K`：全局搜索并跳转到编辑模块。
- `Ctrl/Cmd + S`：立即保存工程。
- `Ctrl/Cmd + Z`：撤销。
- `Ctrl/Cmd + Shift + Z`：重做。
- `Esc`：关闭最上层对话框或返回上一级。

发布前建议在 1440×900 和 1280×720 各完成一次试玩，并确认线索、触发器、推理和资源都能到达。
