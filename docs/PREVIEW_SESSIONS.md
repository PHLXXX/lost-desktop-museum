# 试玩会话隔离

工坊试玩不是一套简化播放器。它先把当前 `CaseDraft` 编译为不可变 `CaseDefinition`，再注册临时 `preview-<projectId>` 案件并打开正式 `Desktop`、应用、线索、窗口和推理引擎。

## 进入试玩

1. 编译和正式校验必须通过。
2. `PreviewSession` 深拷贝当前玩家 `GameSave` 与窗口状态。
3. 临时案件使用独立 case ID 注册，只存在于内存注册表。
4. 游戏状态切换到临时 ID，窗口恢复为试玩初始布局。
5. 顶部始终显示“试玩模式”横幅和返回入口；调试面板显示事件、线索与触发状态。

## 退出试玩

退出时取消待写存档，删除临时案件对应的 localStorage 存档，注销临时定义，并恢复进入前的玩家状态和窗口状态。因此试玩中发现的线索、解锁、关系、窗口移动和调试动作都不会污染正式馆藏进度，也不会写回草稿。

试玩只验证进入时的编译快照。返回编辑器后的修改需要重新进入试玩才能生效，这保证每次测试结果可对应到明确 revision。

如果试玩初始化失败，编辑器保留当前工程和资源，不清除 IndexedDB；作者可回到校验中心修复后重试。
