# 社区安装安全

Registry 是可审计的发布目录，但不会被客户端完全信任。下载前显示发布者、版本、内容提示、许可证、引擎要求与占用；下载支持取消且不把 Blob 放进全局状态。客户端核对登记大小与 SHA-256，然后复用正式 `.ldmcase` 校验器检查 ZIP 路径、重复项、加密、符号链接、压缩比、文件类型、签名、大小、Schema、资源哈希、引用和可达性。

包内 caseId、版本与作者还必须和 Registry 详情一致。案件禁止 JavaScript、HTML、SVG、WASM、Shell、可执行文件和远程资源。写入失败会显式回滚；哈希或包校验失败没有“强制继续”。当前 Registry 没有独立数字签名，这是现阶段限制，因此 GitHub 历史、HTTPS、登记哈希与客户端复验必须同时保留。
