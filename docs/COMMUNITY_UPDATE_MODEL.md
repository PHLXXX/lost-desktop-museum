# 社区更新与回滚

更新由用户进入社区或“我的档案”后检查，不在后台静默安装。版本按语义化版本比较，并检查 `active`、`deprecated`、`blocked`、客户端引擎范围和作者声明。

客户端不会只相信声明：它比较当前存档中的已发现/固定线索、打开/解锁/恢复内容、证据关系、窗口和已触发事件。全部保留为 `compatible`；存在被删除引用或作者要求检查时为 `review-required`；ID 不同或作者明确不兼容时为 `incompatible`。后两者必须由玩家选择保留兼容进度、重置本案或取消。

更新前当前包进入回滚历史，最多保留两个旧版本。回滚再次执行哈希、包校验和兼容检查；失败恢复更新前状态。`deprecated` 仍可游玩，`blocked` 禁止新安装/更新，但不会远程删除已安装副本或进度。
