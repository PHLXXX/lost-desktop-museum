# 深度调查玩法指南

“深度调查”是 v0.6.0 加入的本地玩法层。它建立在既有线索、事件、证据关系和最终推理之上，不改变案件真相，也不要求账户或联网。

## 玩家流程

进入调查桌面后，任务栏会显示 `调查目标 n/m`。点击该按钮，或从 `A/OS → 调查目标与提示` 打开右侧辅助台。面板不会关闭或替换正在阅读的案件窗口。

辅助台包含三个页面：

- 调查目标：显示当前公开的主要与可选目标。隐藏目标只会在作者设定的调查条件满足后出现。
- 分析提示：为尚未记录的线索提供渐进帮助。
- 调查挑战：预览结案时可达成的专精条件；当前周目提交推理后结算。

按 `Esc` 时，界面会依次关闭提示确认、深度调查面板，再打开系统菜单，不会因此丢失进度。

## 三点分析额度

内置案件默认提供 3 点分析额度。每条提示固定分三层，必须按顺序使用：

1. 调查方向：指出值得核对的信息领域。
2. 操作建议：说明应尝试的调查动作。
3. 精确定位：指出具体应用或记录。

每显示一层消耗 1 点，并先显示消耗确认。已记录线索不能继续消耗提示；额度不足时按钮会禁用。使用过的提示随当前案件存档保存，重新进入仍然可见。

提示不是通关门槛。使用提示不会阻止提交最终推理，但会影响要求“无提示”的调查挑战。

## 目标、挑战与档案注记

目标状态由现有案件记录实时推导，不在存档中复制第二份完成状态。目标可以基于线索、剧情事件、触发器或证据关系，也可以组合多个条件。

挑战只在提交最终推理后结算，不会封锁主结局。可用条件包括：

- 发现全部线索；
- 不使用提示；
- 推理达到指定分数；
- 建立指定数量的正确关系；
- 完成指定调查目标。

结算页会显示目标完成数、本次挑战、提示层数、调查用时及本次选中的档案注记。符合多个注记时，系统选择作者设置的最高优先级；没有匹配项时仍显示案件原有结局。

档案馆以 `专精 x/y` 展示历史上已达成挑战的并集。重新调查会清除本轮线索、提示、关系、解锁和窗口状态，但保留最高分、历史专精与全局设置。

## 通关奖励与个人馆藏

提交最终推理后，系统会按本次真实调查状态结算三类奖励：

- 纪念藏品：完成一次推理即可获得的案件纪念物；
- 专精徽章：要求全线索、无提示、高分或正确证据关系等进阶表现；
- 系统主题：满足较高要求后解锁的 ARCHIVE/OS 外观。

结算页会同时显示本次获得的奖励，并以“首次解锁”或“已收藏”区分新旧记录。档案馆导航中的“馆藏奖励”会列出两个内置案件的所有已知奖励、未解锁条件和来源案件；案件条目以 `奖励 x/y` 显示收集进度。

奖励资料与案件存档分离，并以 `<caseId>:<rewardId>` 去重。重新调查只重置当前周目，不会删除已经获得的奖励；案件被卸载后，已获得记录仍以标题快照留在馆藏中。旧存档已经完成推理但没有奖励结算字段时，返回档案馆会按保存下来的推理与调查状态补发应得奖励。

系统主题仅能从主应用内置白名单中选择。当前包括默认“标准档案”、档案 001 的“候机厅夜色”和档案 002 的“信号室蓝图”。案件不能携带 CSS、脚本、远程图片或自定义主题 ID；奖励不提供提示额度、答案、分数或其他玩法优势。

## 当前案件配置

- 《没有出发的旅行》：5 个目标、12 组定制提示、5 个挑战、2 个条件档案注记、3 项专属奖励。
- 《零点后的回声》：5 个目标、6 组定制提示、5 个挑战、2 个条件档案注记、3 项专属奖励。
- 最小可玩模板《消失的备用钥匙》：3 个目标、6 组定制提示、4 个挑战、1 个条件档案注记、2 项奖励示例。

## 旧案件与旧存档

`CaseDefinition.formatVersion` 仍为 1，`gameplay` 是可选字段。v0.5.0 及更早、未包含该字段的 `.ldmcase` 会在运行时确定性生成：

- 基础线索目标与完整归档目标；
- 存在关键矛盾时生成关系目标；
- 每条线索一组基于来源、动作和目标记录生成的三层提示；
- 无提示、全线索、精准结案，以及可用时的关系挑战；
- 一个完成推理即可获得的兼容藏品，以及一个要求全线索和 90 分的兼容徽章；
- 原案件结局，不生成额外档案注记。

这些默认内容只存在于运行时，不会写回或改动导入包。GameSave v3 会迁移为 v4，新增空的提示使用和专精记录；未知提示 ID 会被忽略，损坏的使用次数会被规范化。

## 档案工坊创作

在工坊左侧选择“玩法设计”。作者可以关闭自定义玩法并使用兼容默认值，也可以配置：

- 0—9 点初始分析额度；
- 主要/可选目标及其完成、公开条件；
- 每条线索的三层提示文案与消耗；
- 调查挑战及白名单条件；
- 条件档案注记、优先级与白名单条件。
- 通关藏品、专精徽章、预置主题及其白名单条件。

玩法条件复用现有声明式条件构建器，不允许 JavaScript、任意表达式或远程执行。完整校验会拒绝重复 ID、缺失引用、不可能的线索/关系数量和无法支付的首层提示。导出 `.ldmcase` 后仍执行既有 Schema、引用、可达性、资源与 ZIP 安全校验。

## 本地与隐私边界

目标、提示、专精和结算数据只进入当前设备。通关奖励存入独立的本机馆藏资料。它们不会上传到社区，不会形成公开成就或排行榜，也不会改变收藏、私人评分和私人备注的本地隐私边界。已安装社区案件可离线使用全部深度调查功能。

## 当前限制

- 每组提示固定为三层；暂不支持可变层数或恢复分析额度。
- 挑战只在提交推理时结算，没有计时挑战或在线排行。
- 旧案件的自动提示由已有元数据生成，准确但不具备作者定制文案的叙事细节。
- 条件档案注记用于补充调查评价，不会生成新的剧情分支或可执行事件。
- 奖励没有云同步；清除浏览器站点数据会清除本机馆藏。主题限于当前三套内置配色。
