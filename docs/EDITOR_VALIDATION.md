# 编辑器校验中心

校验中心把草稿编译、Zod 结构校验、依赖分析和安全检查合并成可定位的问题列表。每项问题包含严重度、类别、代码、消息、字段路径和可选实体 ID。

## 严重度

- `error`：阻止试玩发布或正式导出。
- `warning`：允许继续，但提示可能无法到达或体验不完整。
- `info`：不影响正确性的优化建议。

## 主要检查

- 必填元数据、合法语义版本、稳定且唯一的 ID。
- `manifest.caseId` 与正式定义 ID 一致，用户案件不能覆盖内置 ID。
- 事件、线索、核心证据、正确答案、关系和资源引用存在。
- 条件不超过 5 层/30 节点，不存在循环依赖。
- 用户案件推理题总分为 100，结果等级无缝覆盖 0—100。
- 线索来源应用已启用，应用 `componentKey` 已在运行时注册。
- 资源存在、大小/哈希一致，第三方案件不含 SVG 或远程资源。
- 文本不含脚本、危险嵌入、`javascript:` 协议或可执行字段。

## 发布门

发布操作会重新编译，不信任界面上一次校验结果。生成 ZIP 后立即重新导入，复查中央目录、校验和、Schema、语义引用和资源完整性；任何错误都会阻止下载。

模板验证命令：

```bash
npm run validate:cases
npm run validate:editor-examples
npm run package:editor-examples
```
