# Project Rules

- UI text is Chinese. Variables, type names, component names, and filenames are English.
- Case content must be data-driven and must not be scattered through React components.
- Each file owns one clear responsibility. Avoid React components over 300 lines.
- Do not connect an external AI API, backend server, database, or login system.
- Do not commit secrets, tokens, cookies, private user data, or machine-specific paths.
- Add a failing test before new behavior, or add focused tests in the same change for configuration and generated assets.
- Run lint, tests, and build after every milestone.
- Do not claim completion before the relevant verification has passed.
- Keep Git commits small and focused. Never force push.
- Do not imitate real Windows, macOS, or messaging-product trademarks or copyrighted icons.
- Every production asset must be local. Do not hotlink images, fonts, audio, or scripts.
